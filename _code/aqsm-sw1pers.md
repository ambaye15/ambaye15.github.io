Automated Quantification of Stereotypical Motor Movements via Sliding Windows and 1-Persistence Scoring. A Python package for analyzing repetitive motion patterns using pose estimation and topological data analysis. Developed to support the classification of stereotypical motor movements in autism, but applicable to any dataset where the goal is to quantify recurrent patterns in time series or motion in video.
